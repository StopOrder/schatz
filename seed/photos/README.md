# seed/photos — 숨은 스팟 시드 사진을 여기에 넣는다

- **카메라 원본 JPG**만. 카톡·인스타·웹을 거친 사진은 GPS가 지워져 있어 핀이 안 박힌다.
- 아이폰은 HEIC가 아니라 JPG로 가져온다(설정 → 카메라 → 포맷 「높은 호환성」, 또는 맥에서 내보내기).
- 파일 이름은 그대로 둔다. 몇 장이든 좋다(10~30장 권장).
- `seed/captions.txt` 에 한 줄씩 `파일명 | 장소 이름 | 한 줄 설명 | 위도 | 경도 | 방향` 을 적으면 상세 화면에 뜬다(뒤 세 열은 선택). GPS 없는 사진은 여기 좌표로 핀이 박힌다. 캡션이 없으면 「지역 · 유명지에서 N km」로 자동.
- 웹에서 받은 사진은 EXIF가 없다 → 2026-09-18 12:25 사람이 장소 좌표를 EXIF에 심은 사본을 넣었다(좌표는 장소 기준 근사치).
- 라이브 업로드 시연용 사진 1~2장은 `seed/demo-upload/` 에 따로 넣는다(GPS 있는 것). 비어 있으면 에이전트가 시드에서 한 장 옮겨 쓴다.
